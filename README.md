## Set Up
1. Pull this repo to you local machine or onto a DeepDish server.
2. We first set up the conda environment. Use `cd` commands to navigate into this repository. Then, run `conda create --prefix ./.venv python=3.12`.
3. Activate this virtual environment: `conda activate ./.venv`.
4. Install the necessary requirements, `pip install -r requirements.txt`.
5. If you would like to run the attached notebook, to generate plots, create a jupyter notebook kernel for this environment: `ipython kernel install --user --name=<any name for kernel>`.

## Instructions for running DQN models.
1. The following instructions should be run from the base of this directory. 
2. You can modify the hyperparameters for training by editing the parameters in the `main()` method in the respective files `src/cartpole/cartpole_dqn `, `src/mspacman/mspacman_dqn`. 
3. To run the models, execute the following commands: 
``` 
python3 -m src.cartpole.cartpole_dqn    # Runs DQN for Cartpole-v1
python3 -m src.mspacman.mspacman_dqn    # Runs DQN for MsPacman-v5
```
4. [WARNING] Training can take some time, especially for the MsPacman environment. On a single GPU card, 7,000 episodes can take 3-4 hours. As such, the use of a terminal multiplexer, Tmux, is highly encouraged especially when running on a remote server. To create a new Tmux, `tmux new -s dqn-cartpole` and `tmux new -s dqn-pacman` to run both models simultaneously. Then, run `tmux attach -t dqn-cartpole` and `tmux attach -t dqn-pacman` to enter these terminals and run the corresponding scripts using the commands from step 3.
5. Model weights, logs, and associated outputs are stored in `output` under each respective path for a given environment under `src`, reference [directory](#directory-structure) for more information.

## Instructions for running Validation Tests
1. Ensure that `run_validations.sh` has appropriate permissions: `chmod +x scripts/run_validations.sh`.
2. Then, execute ` ./scripts/run_validations.sh`. 
3. The results of the edge cases and validations for each environment and model will be stored under `validation_output.` from the base directory. Any associated plots will be stored under `figures/`.
